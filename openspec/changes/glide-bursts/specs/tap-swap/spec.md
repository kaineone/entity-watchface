# Spec Delta

## ADDED Requirements

### Requirement: Double tap swaps
The top row SHALL swap to steps (and heart rate on rectangular watches) on two taps within
700 ms. A single tap SHALL only start a burst. The settings label reads "Double tap to show steps
and heart rate".

#### Scenario: Single flick
- **WHEN** the user flicks the wrist once
- **THEN** a burst starts and the top row stays on the date
