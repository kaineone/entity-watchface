# Spec Delta

## Purpose
Defines Entity's appstore material and the condition for publishing it.

## ADDED Requirements

### Requirement: Owner approval before publishing
Nothing SHALL be published or submitted to the Pebble appstore until the owner has confirmed every
word of the listing and the assets. The listing file SHALL carry a visible draft notice until then.

#### Scenario: Draft listing
- **WHEN** the listing has not been approved
- **THEN** `store/listing.md` starts with a draft notice and no publish command is run

### Requirement: Store art
Screenshots SHALL be unscaled emulator captures at each platform's native resolution. The banner
and icons SHALL be generated by `tools/make_store_assets.py` from the face's fonts and palette with
no anti-aliasing; banner text SHALL use the colours as the Time 2 display renders them so it matches
the screenshot beside it.

#### Scenario: Regenerate art
- **WHEN** `python3 tools/make_store_assets.py` runs
- **THEN** it writes `store/banner-720x320.png`, `store/icon-144.png` and `store/icon-48.png`
